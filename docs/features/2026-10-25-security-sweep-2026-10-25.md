# Feature: Block other websites from the local server

**Branch:** security/sweep-2026-10-25
**Date:** 2026-10-25 local (2026-10-25 UTC)

## Summary
`server.js` now refuses requests whose `Host` is not `127.0.0.1:<port>` or
`localhost:<port>`, and refuses endpoint calls that a browser marks as coming
from another site. The hooks need no change.

## Motivation
Before this change, any page open in the user's browser could:
- start and stop sets with `<img src="http://127.0.0.1:7887/promptups/start">`;
- write fake rows to `sessions.json` with a `text/plain` form POST;
- with `--ai-coach` on, run `claude -p` with text it chose in `moment` and
  `exercise`. That spends the user's Claude quota and puts attacker text into
  a prompt that runs with the user's own Claude Code settings.

DNS rebinding also let such a page read the replies, including the first line
of the `claude -p` output from `/api/quip`.

## What changed
- `server.js`: `hostAllowed`, `crossSite` and `isEndpoint` helpers, checked at
  the top of `handle()`. The Origin allowlist uses the bound port, so
  `startServer(0)` in tests works.
- `tests/server.test.js`: four tests. Two of them fail on the old server.
- `.github/workflows/dependency-review.yml`: actions pinned to commit SHAs,
  `persist-credentials: false` on checkout.
- `docs/usage.md`: a section on requests from other websites.

## Notes
- PR #8 (capability token) is the larger fix and is still open. It needs every
  user to run `promptups init` again. This change does not, and it does not
  replace #8: a local process can still call the endpoints.
